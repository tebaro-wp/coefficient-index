# شاخص ضریب Tebaro

این مخزن، ضریب عددی اختیاری کالیبراسیون Tebaro را برای محاسبات تخمینی قیمت‌گذاری محصولات منتشر می‌کند.

خروجی عمومی فقط شامل یک ضریب بدون واحد و متادیتای محدود است و نرخ جداگانه ارزها، فهرست منابع، نشانی منابع، لاگ جمع‌آوری، اطلاعات مشتری، سفارش، محصول، آمار تحلیلی یا تله‌متری را منتشر نمی‌کند.

## فایل عمومی

`coefficient.json`

## مستندات پروژه

https://tomanify.github.io/

Tebaro یک ابزار قیمت‌گذاری و تبدیل برای وردپرس/ووکامرس است. این ضریب یک پارامتر تخمینی برای کالیبراسیون محاسبات است و نرخ خرید یا فروش ارز، سرویس صرافی، کارگزاری، حواله یا مشاوره مالی محسوب نمی‌شود.

استفاده از این فید اختیاری است و نرم‌افزار مصرف‌کننده باید اعتبار، تازگی و سازگاری نسخه شِما را قبل از استفاده بررسی کند.
