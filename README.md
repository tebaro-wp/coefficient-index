# Tebaro Coefficient Index

Public scalar calibration coefficient feed for Tebaro product-pricing estimates.

The public feed contains one dimensionless calibration coefficient and limited metadata. It does not publish per-currency exchange rates, provider lists, source URLs, collection logs, customer data, order data, product data, analytics, or telemetry.

## Public feed

`coefficient.json`

Raw file:

https://raw.githubusercontent.com/tebaro-wp/coefficient-index/main/coefficient.json

## Documentation

https://tomanify.github.io/

## Scope

Tebaro is a WordPress/WooCommerce product-pricing and conversion tool. The coefficient is an estimate-calibration parameter and is not a currency buy/sell quotation, exchange service, brokerage service, remittance service, or financial advice.
